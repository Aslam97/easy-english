## PR description

### Fix CSV export dropping rows with newlines inside quoted cells

**Problem**

`exportRows()` dropped rows when a cell contained a newline inside quotes.

**Cause**

The code split the file on `"\n"` before it parsed the quotes. A quoted cell with a newline was split into two pieces, and the row was lost.

**Fix**

`exportRows()` now uses the streaming parser `csv-parse` 5.5, which reads quotes first and so handles newlines inside cells correctly.

**Tests**

Added 3 tests that cover quoted newlines.

**Performance**

Exporting 10,000 rows takes 1.8 s now, compared with 1.2 s before. It is slower, but we think it is acceptable.

**Compatibility**

- No breaking changes.
- Requires Node 18 or newer.

**Known issue, not fixed here**

`importRows()` has the same bug. It is tracked in EXP-412 and is not part of this PR.
