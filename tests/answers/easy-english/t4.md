The list renders all items again because every key press changes the state of `SearchPage`. Also, nothing stops the rows from rendering again.

## Why it is slow

1. `SearchPage` keeps `query` in state. Each key press renders `SearchPage` again.
2. `items.filter(...)` runs on every render.
3. `<Row>` is not memoized, so React renders all 2000 rows each time.
4. `onSelect={(id) => select(id)}` is an inline arrow function. It is a new function on every render. So `React.memo` on `Row` alone would not help, because React sees a new prop each time.

## How to fix it

1. Use `useDeferredValue(query)` for the search text. React then renders the list with the old value while you type. You can also use a debounce of 300 ms.
2. Use `useMemo` for the filtered list, so the filter runs only when the items or the query change.
3. Wrap `Row` with `React.memo`.
4. Use `useCallback` for `onSelect`, so the prop keeps the same function between renders. You need both steps 3 and 4. One step alone does not help.
5. With 2000 rows, use virtualization with `react-window`. Then only about 20 rows are in the DOM.

Start with steps 1 to 4. If the list is still slow, add step 5.
