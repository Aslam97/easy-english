## Commit message

```
Fix CSV export that dropped rows with a newline in a cell

The export split the file on "\n" before it parsed the quotes. A cell
that had a newline inside quotes was cut into two rows, so the export
lost rows.

Now `exportRows()` uses the streaming parser `csv-parse` 5.5. The parser
reads the quotes first, so a newline inside quotes stays in the cell.

This change adds 3 tests. It needs Node 18 or newer.

The export of 10,000 rows now takes 1.8 s. It took 1.2 s before.

`importRows()` has the same bug. This commit does not fix it. See
ticket EXP-412.
```

## PR description

### Problem

The CSV export dropped rows when a cell had a newline inside quotes. The code split the file on "\n" before it parsed the quotes. So one cell with a newline became two broken rows.

### Fix

`exportRows()` now uses the streaming parser `csv-parse` 5.5. The parser handles the quotes, so a newline inside quotes stays in the cell.

### Tests

This PR adds 3 tests.

### Performance

The export of 10,000 rows now takes 1.8 s. It took 1.2 s before. The export is slower, but we think the time is ok.

### Notes

- This PR has no breaking changes.
- The change needs Node 18 or newer.
- `importRows()` has the same bug. This PR does not fix it. The ticket is EXP-412.
